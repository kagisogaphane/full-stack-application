# ASP.NET Core Web API & Angular Full-Stack Application

A full-stack web application built with **ASP.NET Core Web API** and **Angular**, showcasing modern web development practices including RESTful APIs, CRUD operations, JWT authentication, and frontend-backend integration.

## Features

- RESTful API development with ASP.NET Core
- Angular frontend with responsive UI
- Create, Read, Update, and Delete (CRUD) operations
- JWT-based authentication and authorization
- Entity Framework Core and SQL Server integration
- Secure and scalable application architecture
- Production-ready deployment approach

## Tech Stack

**Backend**
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- JWT Authentication

**Frontend**
- Angular
- TypeScript
- RxJS

## Key Skills Demonstrated

- Full-stack application development
- API design and implementation
- Authentication and security
- Database integration
- Frontend-backend communication
- Clean architecture principles
- Deployment and environment configuration

## Getting Started

### Backend

```bash
dotnet restore
dotnet run
```

### Frontend

```bash
npm install
ng serve
```

## Learning Outcome

This project was built to strengthen practical full-stack development skills using ASP.NET Core and Angular, with a focus on building secure, maintainable, and production-ready applications.
